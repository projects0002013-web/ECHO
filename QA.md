# Проверка требований ECHO

В текущей облачной среде прошли 15 серверных тестов и 15 браузерных сценариев, а также отдельные настоящие проверки синтеза и персонального голоса через интерфейс. Интерфейс проверен в Chromium при ширине 320, 390, 768 и 1280 пикселей; запросов к внешним сервисам во время основных сценариев не было.

| Критерий | Результат |
| --- | --- |
| 1. Избранные карточки | Проверены добавление, фильтрация и сохранение после перезагрузки. |
| 2. Размер карточек | Переключение и сохранение проверены. |
| 3. Тёмная тема | Переключение и сохранение проверены. |
| 4. Настройка голоса | Проверено сохранение скорости; используются только локальные голоса. В headless Chromium системных голосов нет, поэтому их реальное звучание не проверено. |
| 5. Несколько языков | Сохранение языка проверено; стандартные фразы поддерживают русский, английский, казахский и белорусский. Пользовательский текст сохраняется как введён. |
| 6. Вибрация | Настройка сохраняется. Физический отклик нужно проверить на поддерживаемом телефоне. |
| 7. Поиск | Проверена фильтрация; исправлено отсутствие скрывающего CSS. |
| 8. Категории | Проверена фильтрация по стандартной категории совместно с избранным и поиском. |
| 9. Экстренная помощь | Экран SOS и остановка воспроизведения проверены. Звонок 112 не выполнялся. |
| 10. Конструктор предложений | Проверены сборка из слов, удаление слова и перенос сообщения в форму карточки. |
| 11. Работа без интернета | Проверены перезагрузка интерфейса и воспроизведение сохранённой записи при отключённой сети. Шрифты включены локально. |
| 12. Запись голоса близких | Проверены импорт WAV, настоящая цепочка AudioWorklet с тестовым микрофоном, сохранение и удаление аудио. |
| 13. ИИ-адаптация голоса | Chatterbox установлен, веса скачаны и проверены. Настоящий API-синтез создал непустой WAV длиной 5,08 с. Проверены настоящая генерация через интерфейс и офлайн-повтор без нового запроса. Тестовый образец — denis_test.wav из репозитория, повторённый трижды; это не запись пользователя. Сходство с его голосом требует собственного образца. |
| 14. Адаптация под телефоны | Проверены отсутствие горизонтального переполнения и размеры кнопок не менее 44×44 пикселей. Перекрытие подписей меню исправлено. |
| 15. Тестирование | `python3 -m unittest discover -s tests -v` и `tests/browser_smoke.py` проходят; тесты реального синтеза выделены отдельно. |
| 16. Публикация | PWA и инструкции подготовлены. Публичный сайт и магазины приложений не опубликованы. |

Установка `bash scripts/setup.sh --voice` повторно выполнена успешно, включая вспомогательные языковые данные и проверки контрольных сумм. Локальный сервер запущен из `.voice-venv`. Для собственного голоса запишите образец в настройках и выберите персональный голос. Отдельный реальный тест: `.venv/bin/python tests/voice_smoke.py --reference <ваш-образец.wav>`. Проверка настоящего сценария в браузере: `.venv/bin/python tests/personal_voice_browser.py --reference <ваш-образец.wav>`.

Дополнительно модель загружена в новом процессе и выполнила синтез с заблокированными Python-сетевыми соединениями: попыток соединения — 0, выходной WAV — 2,84 с. Это проверяет работу после установки без скачивания данных во время синтеза.

В публично размещённой версии образец не отправляется на сайт: генерация разрешена только на localhost/127.0.0.1. Это отдельно проверено в браузере. Карточки и записи доступны в PWA; новая ИИ-генерация на телефоне без локального движка не поддерживается.

В черновике среды сохранены `install_script`, `start_skill` и сетевые домены установки. Сохранение черновика не является публикацией среды. Публичный хостинг и App Store/Google Play не настроены.

Сходство персонального голоса с реальным образцом, микрофон и вибрацию нужно дополнительно проверить с пользователем на его устройстве.
