# ECHO — конфиденциальность и сохранность данных (проект политики, 2026-11-08)

> **Статус:** текст для проверки перед публичным запуском. Не выдавать за завершённый юридический аудит. Проверять фактическое поведение каждой опубликованной сборки.

## Назначение

ECHO — бесплатный коммуникатор дополнительной и альтернативной коммуникации (AAC). Основные функции: фразы, карточки, изображения, сохранённые голосовые записи, локальное озвучивание, SOS-экран и резервные копии.

## Где находятся данные

- Пользовательские карточки, категории, настройки и история (если включена) хранятся в браузерном локальном хранилище приложения.
- Личные изображения и аудиозаписи сохраняются локально через IndexedDB.
- Основные функции ECHO рассчитаны на использование без регистрации и обязательного аккаунта.
- Работа системного голосового движка зависит от голосов, установленных в ОС. ECHO не может обещать отсутствие сетевого поведения **стороннего** системного TTS-движка; для максимальной приватности используйте офлайн-голоса или собственные записи.
- В тестовую Android APK включена **общая английская модель PocketTTS**, не обученная на голосовых записях пользователя. Во время генерации личный WAV-образец и текст обрабатываются локально в приложении и не отправляются в облако. Модель при первом использовании копируется в приватную папку приложения; проверка реального поведения на телефоне ещё требуется. Необязательный локальный компьютерный сервер используется отдельно.

## Микрофон и файлы

- Разрешение на микрофон требуется для записи; для обычных готовых карточек оно не требуется.
- Аудио, фото и файлы резервных копий должны обрабатываться только после действия пользователя.
- Android «ECHO Тест» имеет отдельный пакет `org.echo.aac.preview`; его данные изолированы от основной версии `org.echo.aac`.
- Наличие кнопки «Позвонить 112» не означает, что ECHO автоматически набирает номер: действие должно подтверждаться пользователем. Экстренные службы не заменяются приложением.

## Экспорт и удаление

- Пользователь может создать резервный JSON-файл с карточками и изображениями; запись голоса включается по отдельному выбору.
- **Резервные файлы не шифруются.** Человек, которому передан такой файл, может прочитать карточки и вложенные записи. Сохраняйте копии в защищённом месте, не публикуйте их.
- Удаление данных ECHO через системные настройки приложения может быть необратимо без заранее сохранённой копии.
- История фраз может быть отключена в настройках. Перед заявлением о полном удалении всех данных необходимы отдельные технические проверки.

## Что ECHO не должен делать

- Не отправлять аудиозаписи, карточки или сообщения на сторонние аналитические сервисы без отдельного явного согласия.
- Не включать частные голосовые модели и пользовательские записи в общедоступный APK или GitHub-репозиторий.
- Не требовать платные облачные API для основных возможностей.

## Контакты и перед выпуском

**Нужно заполнить до публикации:** ответственный разработчик/организация, контакт для вопросов конфиденциальности, дата вступления политики в силу, перечень фактических сетевых запросов и зависимостей, сведения о хранении, обработке и процедуре запросов пользователей. Нельзя публиковать эту черновую политику как подтверждение нормативного соответствия.
