# ECHO — твой голос

Коммуникатор с большими карточками для людей, которым трудно говорить или быстро подбирать слова. Можно создавать свои фразы с иконками, собирать сообщения из слов, сохранять избранное и воспроизводить записанный голос близких. Интерфейс Executive Light поддерживает светлую, тёмную и высококонтрастную темы.

## Запуск на своём компьютере

Для карточек, записи и офлайн-работы достаточно Python 3.10+ и современного браузера:

```bash
cd ECHO
python3 echo_server.py
```

Откройте локальный адрес, напечатанный сервером, в браузере на этом же компьютере. Сервер слушает только loopback и отдаёт только публичные файлы приложения, не `.git`, аудиообразцы или окружения Python. В облачной среде используйте существующий checkout `/workspace/ECHO`; отдельный Git worktree не нужен.

Приложение работает как устанавливаемое PWA. На Android используйте «Установить ECHO», если браузер предлагает установку. На iPhone: «Поделиться» → «На экран Домой». Для размещённого приложения нужен HTTPS. Публичное размещение и публикация в магазинах приложений — отдельные действия; этот репозиторий сам ничего не публикует.

## Собственные карточки: порядок и изображения

Кнопки «Вверх» и «Вниз» меняют порядок собственных карточек относительно видимых соседей, включая поиск, категорию и избранное. Они доступны с клавиатуры и на сенсорном экране. Порядок хранится в существующем массиве карточек; отдельной системы сортировки нет. Перетаскивание не добавлено: приоритет отдан явным доступным кнопкам.

В окне создания и редактирования можно загрузить JPEG, PNG или WebP до 8 МБ и 20 миллионов пикселей. ECHO проверяет формат, преобразует изображение в WebP с максимальной стороной 640 пикселей и лимитом результата 1 МБ. Изображения хранятся как Blob в отдельной IndexedDB `echo-card-images`, метаданные карточек в прежнем localStorage содержат только идентификатор. Сеть для изображений не используется. Старые карточки с emoji сохраняют совместимость. Кнопка удаления изображения возвращает emoji; заменённые изображения и изображения окончательно удалённых карточек освобождаются. При недоступной IndexedDB используется emoji.

При ошибке сохранения окно карточки остаётся открытым с введённым текстом. Повреждённый массив карточек не перезаписывается. Для категорий используется атомарная запись `echoCategoryState` с чтением прежних ключей до первой успешной записи. После удаления доступна отмена в течение пяти секунд; выход со страницы завершает ожидающее удаление.

Браузерное хранилище ограничено свободным местом и может быть очищено браузером или пользователем; оно не заменяет резервную копию. На телефоне дополнительно проверьте выбор фото, системный голос, фокус и управление с VoiceOver/TalkBack.

## Записи своего голоса и голоса близких

В **Настройки → Мой голос и записи близких** выберите «Озвучку одной фразы», укажите её текст и запишите её или загрузите аудиофайл. Прослушайте подготовленную запись, затем нажмите «Сохранить запись». До этого она остаётся только в памяти, а прежняя запись не меняется. Затем включите режим «Записи фраз». ECHO воспроизведёт запись для совпадающего текста на выбранном языке. Для остальных сообщений используется локальный голос устройства. Запись фразы не является клонированием голоса.

Запись длится до 30 секунд. Микрофон доступен на localhost и по HTTPS; доступ запрашивается только после нажатия кнопки записи. При уходе из приложения или из экрана настроек микрофон выключается. Аудиофайлы преобразуются в моно WAV на самом устройстве. Тихие, слишком короткие и слишком длинные записи отклоняются.

## Выбор голоса и ограничения браузера

В настройках используйте существующий выбор источника: «Голос устройства / Piper», «Записи фраз» или «Мой персональный голос». Piper используется в первом режиме только при включённой настройке Piper ниже. Смена источника, системного голоса и языка останавливает прежнюю речь; автоматического произнесения при смене настроек нет. Скорость 0,5–2× применяется к следующему воспроизведению.

Выбор системного голоса запоминается отдельно для русского, казахского, английского и белорусского. Приложение показывает только голоса, помеченные браузером как локальные. Если выбранный голос исчез, предпочтение сохраняется, интерфейс предупреждает о временном использовании другого локального голоса того же языка. Список обновляется по `voiceschanged`; после появления голосов нужно нажать фразу снова. Пустой список не запускает отложенную старую фразу. Реальное наличие голоса и его офлайн-работа зависят от устройства и установленного движка.

Кнопка «Проверить голос» произносит короткий текст на выбранном языке через выбранный источник. Общий статус и кнопка остановки доступны как на экране фраз, так и в настройках. При недоступном ИИ или Piper предложены кнопки выбора другой озвучки; приложение не подменяет источник без нажатия пользователя. Если браузер блокирует аудио после асинхронного чтения, кнопка «Воспроизвести подготовленную запись» повторяет воспроизведение по прямому нажатию, без новой генерации и без обхода ограничений браузера.

Новая запись сначала доступна для прослушивания и отказа от сохранения. Для нового образца персонального голоса обязательно подтверждение прав на его использование. Прежние записи в IndexedDB продолжают читаться без изменения формата. Выход из настроек или смена языка отменяет текущую запись/несохранённый предпросмотр; дорожки микрофона освобождаются даже при позднем разрешении доступа. Ошибка записи в IndexedDB оставляет предпросмотр для повторной попытки. Для восстановления после очистки данных браузера нужна отдельная резервная копия: браузерное хранилище не является гарантированным постоянным архивом.

## Персональный голос: локальная нейросеть

**Chatterbox Multilingual** создаёт новые фразы по образцу голоса. Поддержаны русский и английский в интерфейсе ECHO. Для казахского и белорусского выбирайте записи или локальный голос устройства. Модель сохраняет собственную встроенную маркировку синтетического аудио. Сходство зависит от качества записи и не гарантируется; оценивать его нужно на собственном образце.

Нейросеть проверена на Linux с Python 3.12. Скрипт установки предназначен для Linux; на Windows можно использовать WSL. Планируйте 16 ГБ RAM и не менее 6 ГБ свободного диска. CPU поддерживается; первый запрос дополнительно загружает модель в память. На телефоне без локального движка доступны карточки, записи и ранее сохранённые фразы; новая генерация в мобильном браузере не выполняется.

Первичная установка требует интернета:

```bash
bash scripts/setup.sh --voice
```

Скрипт создаёт отдельное `.voice-venv`, ставит проверенные CPU-версии PyTorch и зависимости из `requirements-voice-lock.txt`, затем скачивает модель из официального `ResembleAI/chatterbox`. Загрузчик фиксирует commit SHA, проверяет SHA-256 больших файлов и Git SHA-1 небольших файлов, сохраняет `voice_models/echo-manifest.json`. При ошибке доступа или проверки установка останавливается, проверки TLS и контрольных сумм не отключаются. Можно передать конкретный commit:

```bash
.voice-venv/bin/python download_voice_model.py --revision <полный-commit-SHA>
```

После установки остановите ранее запущенный сервер и используйте:

```bash
.voice-venv/bin/python echo_server.py
```

Запишите 6–30 секунд спокойной речи в «Образец моего голоса», прослушайте запись, подтвердите, что это ваш голос или у вас есть разрешение владельца на создание персонального голоса, и нажмите «Сохранить запись». Затем нажмите «Проверить локальный ИИ» и выберите «Мой персональный голос». При отсутствии модели интерфейс явно сообщает об этом. Для новой фразы сервер принимает образец только по локальному HTTP, не отправляет его в облако, загружает только локальные веса и возвращает WAV. Подготовка модели не требует загрузки пользовательского аудио. Одновременная генерация двух фраз не допускается.

Сгенерированные фразы сохраняются в браузере: последние 50 вариантов доступны для повторного воспроизведения без интернета и без работающего сервера. «Остановить голос» прерывает ожидание и воспроизведение; уже начавшееся вычисление на сервере может завершиться в фоне.

Сетевой доступ для первого скачивания: `huggingface.co`, `us.aws.cdn.hf.co`, а при использовании Xet — `cas-server.xethub.hf.co` и `cas-bridge.xethub.hf.co`. В некоторых регионах Hugging Face может направить скачивание на другой CDN; используйте домен из фактической ошибки, а не отключение проверки сертификатов. Для зависимостей нужны PyPI и официальный CPU-репозиторий PyTorch. При синтезе включён офлайн-режим библиотек Hugging Face. Вспомогательные языковые данные заранее устанавливаются в `.voice-cache`; архив pkuseg скачивается с официального GitHub и проверяется по контрольной сумме зависимости. Установку кэша нужно завершить до синтеза.

## Офлайн и личные данные

При первом открытии service worker сохраняет интерфейс, иконки и локальный шрифт Nunito. Работает и на localhost. Голосовые API не попадают в общий кэш приложения. При обновлении статических файлов изменяйте версию кэша в `sw.js`.

Карточки и настройки находятся в localStorage, аудио — в IndexedDB на этом устройстве. Записи не переносятся автоматически в другой браузер или на другое устройство. Публичная версия не отправляет образец голоса на сайт: новый синтез разрешён только на localhost/127.0.0.1. История новых сообщений по умолчанию выключена; её можно включить в настройках и очистить на вкладке «История». Записи можно удалить по одной, удалить образец вместе с созданными фразами или удалить все голосовые данные. Очистка данных браузера также удалит эти данные. Хранилище браузера не является зашифрованным сейфом: используйте защиту учётной записи устройства.

Сервер не сохраняет тексты запросов в журналы, обрабатывает образец во временном приватном каталоге и удаляет временный файл после обработки. Голосовые условные представления остаются в памяти загруженной модели до следующей генерации или остановки сервера. Для полного освобождения памяти остановите сервер.

Сетевые голоса SpeechSynthesis не используются. Если на устройстве нет локального голоса выбранного языка, ECHO сообщает об этом; выбирайте запись, Piper или персональный голос.

## Дополнительный Piper

Piper даёт стандартные нейросетевые голоса, без клонирования образца. При необходимости:

```bash
bash scripts/setup.sh
.venv/bin/python piper_bridge.py
```

Модели `.onnx` и соответствующие `.onnx.json` размещаются в `piper_models/`. Откройте сам ECHO на localhost/127.0.0.1. Bridge отклоняет чужие Origin и Host и не предоставляет wildcard CORS. В настройках Piper укажите локальный сервер, обновите список голосов и выберите модель. Адрес ограничен localhost/127.0.0.1. Модели Piper не включены в репозиторий.

## Мои данные: копия и восстановление

В настройках откройте «Мои данные». «Создать резервную копию» готовит один файл `ECHO-backup-YYYY-MM-DD.json`. Сохраните его из загрузок браузера и проверьте наличие файла: приложение знает время подготовки, но не может гарантировать, что пользователь сохранил загрузку. Личные записи и образец голоса по умолчанию исключены; при необходимости включите соответствующий флажок.

Формат `ECHO-backup`, версия 1: метаданные, данные приложения, бинарные изображения/WAV в Base64 и SHA-256 JSON-полезной нагрузки. Максимум файла — 100 МБ; действуют дополнительные ограничения числа записей и размера изображений/аудио. SHA-256 обнаруживает повреждения, но не является подписью доверенного автора. Файл **не зашифрован**. Получивший его человек сможет прочитать фразы, фотографии, историю и включённые голосовые данные.

Копируются карточки в сохранённом порядке, избранное, быстрые фразы, категории и назначения, параметры интерфейса, языковые/голосовые предпочтения, изображения; история — только при включённом сохранении истории; записи и образец — только по флажку. Не копируются кэш синтезированных фраз, веса моделей, service worker/cache shell, неизвестные ключи localStorage, журнал восстановления и время экспорта. Кэш и shell восстанавливаются приложением автоматически, модели устанавливаются отдельно по инструкции.

Выберите файл для восстановления, проверьте предпросмотр и способ операции:

- **Объединить**: сохраняются текущие настройки; новые карточки добавляются в конец в исходном порядке. При различающихся карточках с одним ID создаётся новый ID и переназначаются ссылки избранного/категорий. Конфликтующие категории также получают отдельные ID; существующая аудиозапись с тем же ключом выигрывает. Идентичные карточки не добавляются повторно.
- **Заменить**: карточки, изображения и настройки заменяются набором из файла. Голосовые данные заменяются, только если они включены в копию; иначе существующие записи остаются. Перед заменой сделайте копию текущих данных.

До подтверждения данные не меняются. Несохранённую запись нужно сначала сохранить или отменить. Перед изменениями сохраняется полный локальный снимок прежнего состояния в IndexedDB `echo-backup-journal`. Записи в двух рабочих IndexedDB выполняются транзакциями, затем обновляются ключи localStorage; только после завершения всех записей удаляется журнал. При ошибке выполняется откат. Если откат не удался (например, нет места), журнал остаётся, а приложение блокирует обычный запуск и предлагает повторить его после устранения причины. На следующем запуске восстановление журнала выполняется **до** загрузки приложения. Не очищайте данные браузера, когда нужен журнал для отката.

Для исключения параллельных писателей допускается одна активная вкладка ECHO на этом origin через Web Locks. Закройте остальные, особенно вкладки старых версий. Браузер без Web Locks может использовать приложение, но резервные операции в нём недоступны. Нужны localhost или HTTPS и доступные localStorage/IndexedDB. Никаких сетевых отправок файлов резервной системой нет. Данные доступны скриптам того же origin, пользователю устройства и расширениям с соответствующими правами; это не зашифрованный сейф. Очистка браузера удалит рабочие данные и локальный журнал, поэтому храните экспорт отдельно.

Проверка резервных сценариев с запущенным сервером:

```bash
.venv/bin/python tests/backup_browser.py
node --check backup.js
```


## Интерфейс и доступность 2.0

В настройках первым расположен раздел «Удобство общения». «Простой режим» оставляет крупные карточки, фразы, избранное, настройки и SOS. Управление карточками, история, быстрые фразы и второстепенные настройки скрываются, но данные не удаляются. Чтобы вернуть все возможности, откройте настройки и выключите тот же переключатель. Режим сохраняется после перезагрузки и включён в резервную копию. Старые копии без этой настройки по-прежнему восстанавливаются; новые настройки требуют обновлённой версии ECHO.

Доступны светлая, тёмная и высококонтрастная темы. Активное состояние отмечено не только цветом, но и подчёркиванием/границей. Выбор темы сохраняется и переносится через копию. Цветовые переходы отключены, чтобы избежать промежуточного низкого контраста; настройка уменьшения движения сохраняется.

Над нижней навигацией находятся постоянные кнопки остановки речи и открытия конструктора сообщений. SOS открывает отдельный экран и не начинает говорить или звонить от одного нажатия по навигации. Нижний отступ контента рассчитывается по фактической высоте меню и панели действий; учитываются safe area и обе ориентации. При заметном уменьшении visual viewport во время ввода фиксированные панели скрываются, чтобы освободить экран. Реальные экранные клавиатуры нужно дополнительно проверить на устройствах.

Ссылка «Перейти к общению» появляется при клавиатурном фокусе. Диалоги карточек и категорий ограничивают Tab/Shift+Tab, закрываются Escape и возвращают фокус. Фон диалога исключается из взаимодействия через inert. Картинки карточек декоративны для диктора: доступное название кнопки содержит произносимый текст. Выбор emoji имеет aria-pressed; декоративные иконки навигации не дублируют текстовые подписи.

Автоматические проверки с запущенным сервером:

```bash
.venv/bin/python scripts/fetch_axe.py
.venv/bin/python tests/accessibility_browser.py
node --check accessibility.js
```

Загрузчик использует axe-core 4.10.3 из официального npm и проверяет SHA-512 пакета. Это только инструмент тестирования, он не включён в приложение и не отправляет пользовательские данные. Нулевой результат автоматического аудита не означает полного соответствия WCAG или успешного тестирования реальными людьми. NVDA, VoiceOver, TalkBack, управление переключателем и работа одной рукой на физических устройствах требуют отдельных испытаний. Автоматическое сканирование/управление переключателем не реализовано: надёжное внедрение потребует совместного тестирования с пользователями и отдельного этапа.


## Четыре языка интерфейса

В настройках доступны Русский (`ru`), Қазақша (`kk`), English (`en`) и Беларуская (`be`). Переключаются меню, формы, встроенные карточки, SOS, конструктор, голосовые настройки, резервное копирование, сообщения и доступные подписи. Выбор сохраняется в прежнем `echoLanguage`; `lang` документа и manifest обновляются без перезагрузки. Смена языка останавливает речь и отменяет несохранённую запись, не запускает старую фразу заново. Предпочтения системного голоса сохраняются отдельно для каждого языка.

Личные карточки, названия категорий, история и быстрые фразы остаются в исходном виде. Сохранённые аудиофразы сохраняют язык и текст записи. Язык интерфейса не переводит личные данные и не устанавливает голоса на устройство. Названия установленных голосов, технические коды и имена файлов сохраняются как получены от устройства/пользователя. Звучание RU/KK/EN/BE зависит от установленных локальных голосов; персональная модель Chatterbox поддерживает в этом проекте RU/EN, а не KK/BE. Для KK/BE можно использовать записи или подходящий локальный голос.

`locales/catalog.json` — единый каталог: **526 ключей на язык**, 2104 значений для четырёх языков. Русские исходные сообщения служат общими ключами; значения — обычный текст. `i18n.js` загружает локальный каталог перед безопасным bootstrap резервной системы. Адаптер привязывает известные тексты/ARIA/placeholder/title к исходному ключу и обновляет динамически созданные элементы. Старые варианты написания сведены в `aliases`; встроенные фразы, слова конструктора и SOS используют тот же каталог. Личные области исключены из DOM-перевода. Переменные подставляются через `{v0}`, `{v1}` и т. д.; переводчик не вставляет HTML.

Для нового сообщения добавьте один исходный ключ и значения во все четыре таблицы `messages`, сохраняя одинаковые placeholders. В коде предпочтительно использовать `echoI18n.t(key, {v0: value})` и `textContent`; личный DOM-текст отмечайте `data-no-i18n`. Нативные alert/confirm/prompt переводятся адаптером с сохранением возвращаемого значения. Новому языку дополнительно нужны код/locale в языковом и голосовом выборе, manifest и список ресурсов service worker.

При отсутствии перевода используется русское значение; неизвестный ключ возвращается как исходный текст и попадает в диагностический `echoI18n.missing`. Тесты проверяют равенство ключей, непустые значения, placeholders и отсутствие неизвестных UI-сообщений в пройденных состояниях. После добавления текста проверьте этот Set на всех затронутых экранах. Каталог, загрузчик и четыре manifest включены в `echo-v20-executive-ui`; офлайн-доступность требует первого успешного открытия с сетью. Если каталог целиком недоступен до установки кэша, появляется явное сообщение об ошибке загрузки вместо частично работающего интерфейса.

```bash
# С работающим echo_server.py:
.venv/bin/python tests/localization_browser.py
node --check i18n.js
```

Носители казахского/белорусского и реальные экранные дикторы ещё не проводили независимое ревью переводов. Границы выполненной проверки и состояние GitHub приведены в QA.md.


## Мой голос — Voice Studio

Кнопка «Мой голос» в шапке открывает студию. Запишите 6–30 секунд собственного голоса или загрузите образец, прослушайте и подтвердите сохранение. Введите новый текст, подтвердите своё согласие и нажмите «Синтезировать»: ECHO отправляет образец только своему локальному Chatterbox на localhost, создаёт новый WAV и предлагает отдельное прослушивание. Эта кнопка всегда запрашивает новую генерацию; воспроизведение записи не подменяет ИИ. «Использовать для карточек» сохраняет прежний режим персонального голоса; созданные карточками фразы используют локальный кэш. «Удалить результат» удаляет текущий WAV из кэша, «Удалить образец и созданные фразы» — образец и весь кэш. Результат студии также остаётся в локальном кэше (до 50 фраз), если сохранение удалось; ошибка сохранения показывается явно.

При отсутствии модели раскройте «Установка локального ИИ» и выполните указанные команды на своём компьютере. Генерация поддерживает русский и английский; KK/BE используют записи или голос устройства. Нужна первая успешная загрузка приложения для офлайн-ресурсов; сам новый нейросинтез требует работающего локального сервера и установленной модели. Стоп отменяет ожидание/воспроизведение и игнорирует поздний WAV; уже начавшееся вычисление модели на сервере может завершиться в фоне.

Критическая проверка: `.venv/bin/python tests/studio_browser.py` при запущенном сервере. Ответы ИИ в успешных сценариях этого теста подставные; настоящий нейросинтез требует установленной модели и собственного образца с разрешением владельца.


## Executive Light и автономный голос

Executive Light — светлая тема по умолчанию: фон #F8FAF8, белые карточки, зелёный #166534, тёмно-зелёный #123D29 и текст #17231B. Сохранённые light/dark/contrast и индивидуальные настройки читаются под прежними ключами. Системные декоративные emoji заменены линейными SVG/текстом; личные изображения, символы и содержимое карточек сохраняются.

В «Моём голосе» есть проверка автономной модели. Обычная PWA не содержит мобильного AI-движка: голос устройства, сохранённые записи и ранее созданные фразы продолжают работать офлайн. Генерация нового текста Chatterbox по-прежнему требует сервера на ПК и не является автономным AI телефона; на публичном сайте её кнопка недоступна с явным объяснением. Новая кнопка мобильного синтеза не добавлена.

Подготовлена **экспериментальная основа**, а не готовое приложение: JS-контракт нативного моста и C++-адаптер PocketTTS/sherpa-onnx с reference audio. Проверка не признаёт модель готовой по одному наличию WebAssembly/WebGPU, требует совместимый движок, модель и подтверждение проверки лицензии. Прототип ограничен EN; RU/KK/BE остаются языками интерфейса и системной/записанной озвучки. Мобильный мост не подключён к генерации карточек. Настоящий автономный AI-синтез не проверен на телефоне. В отдельном Linux CLI выполнен настоящий CPU-инференс с искусственным тестовым сигналом и новым текстом; WAV проверен, качество речи и сходство с человеком не оценивались.

Исследование совместимости/лицензий, ограничения ресурсов и шаги JNI/Swift — в [native/README.md](native/README.md). Код PocketTTS — MIT, sherpa-onnx — Apache-2.0; в совместимом int8-архиве проверена лицензия весов CC BY 4.0; сохранены текст лицензии, атрибуция и хэши файлов. Android APK/iOS-сборка и модели не поставляются. Дополнительная проверка с сервером: `.venv/bin/python tests/executive_browser.py`.

## Безопасная Android-тестовая версия

GitHub Actions `Android Executive Light APK` создаёт **`ECHO Тест`** — отдельный debug-пакет `org.echo.aac.preview` (основной ECHO: `org.echo.aac`). Это позволяет тестировать дизайн и офлайн-голос на одном телефоне, не удаляя пользовательские карточки и записи в основном приложении. При первом запуске тестовая версия имеет **отдельное пустое хранилище**. Автотесты в CI проверяют отдельный ID приложения, подпись APK и упакованные офлайн-ресурсы.

**Важные ограничения:** такой debug APK **не проверяет обновление основной версии поверх существующей**, а новая сборка GitHub Actions может быть подписана другим отладочным ключом и не обновить прежний «ECHO Тест». Если Android просит удалить прежний тестовый APK, сначала экспортируйте данные **именно из «ECHO Тест»**. Никогда не удаляйте основное приложение ECHO ради установки тестовой версии. ## Локальный персональный AI-голос — PocketTTS

В тестовую Android APK интегрированы **настоящий sherpa-onnx 2.0.1 Java/JNI**, полная английская модель **PocketTTS int8 2026-01-26** и вызов персонального голосового синтеза по WAV-образцу. Веса и библиотека скачиваются только в GitHub Actions при сборке; на Android модель проверяется по SHA-256 и устанавливается в приватное хранилище при первом синтезе. Голосовой образец и текст не отправляются на сервер. В интерфейсе Voice Studio необходимо подтвердить согласие владельца голоса.

- ✅ [Реальный PocketTTS inference smoke](https://github.com/projects0002013-web/ECHO/actions/runs/42547174434) на Linux создал WAV (1 071 404 байта) за 5,11 секунды из тестового синтетического аудио. Это не mock.
- ✅ [Android APK с JNI и моделью](https://github.com/projects0002013-web/ECHO/actions/runs/42546676817) успешно собиралась. Последующие Android-сборки сохраняют изолированный пакет `org.echo.aac.preview`.
- ⏸ Запуск самой нейросети на Redmi Note 14, качество персонального голоса, время генерации и расход памяти на устройстве **не проверены**.
- ⚠️ PocketTTS поддерживает английский язык. Русский, казахский и белорусский продолжают использовать системный голос или заранее сохранённые записи.
- ⚠️ Это тестовая сборка, а не стабильный релиз ECHO 1.0. Основной `org.echo.aac` не заменяется.

**Версии/лицензии:** sherpa-onnx v2.0.1 (Apache-2.0); веса PocketTTS int8 2026-01-26 (CC BY 4.0; LICENSE включён в модельные ресурсы). Источник модели: https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models. Подробности и ограничения: [POCKET_TTS_INTEGRATION.md](POCKET_TTS_INTEGRATION.md), [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md).
