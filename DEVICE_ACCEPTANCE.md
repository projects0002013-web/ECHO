# ECHO 1.0 — обязательная проверка на реальном телефоне

Состояние: **не пройдено** до фиксации наблюдений. Успешная сборка APK и автоматические тесты НЕ означают, что приложение готово для людей, которым нужна надёжная AAC-коммуникация.

## Перед установкой

1. На исходном ECHO откройте **Настройки → Мои данные** и создайте резервную копию **с аудиозаписями**, если они важны. Проверьте, что файл появился в папке загрузок, имеет ненулевой размер и доступен для чтения.
2. Не удаляйте старое приложение и не очищайте его данные: это может безвозвратно удалить сохранённые карточки и записи.
3. **Новые Debug APK устанавливаются как отдельное приложение «ECHO Тест»** (`org.echo.aac.preview`), поэтому рабочий ECHO и его данные не затрагиваются. Приложение ECHO Тест начинает с отдельного пустого хранилища. Не удаляйте основной ECHO.
4. Если Android предлагает **удалить основное приложение ECHO** перед установкой — отмените установку. В этом случае идентичность APK нужно перепроверить. Учтите, что отдельный тестовый пакет **не подтверждает** корректность обновления основной версии поверх старой: для этой проверки потребуется подписанный совместимым ключом релиз.
5. Не используйте демонстрационные SOS-кнопки для реального вызова экстренных служб: проверяйте их только без совершения звонка.

## Другие устройства

- Android-планшет: 7–11 дюймов, обе ориентации, карточки, меню и системные диалоги.
- iPhone: Safari/PWA, VoiceOver, аудио, микрофон, локальное хранилище, экспорт/импорт.
- Windows/десктоп: масштаб 200%, клавиатура, скринридер при наличии.

## Критерии допуска к ECHO 1.0

1. Нет известных критических ошибок, мешающих произнести фразу, и нет потери данных.
2. Резервная копия и восстановление испытаны на реальном устройстве.
3. Тесты Android TTS и записей пройдены без сети.
4. Основные карточки, навигация, SOS и Stop доступны в режиме TalkBack.
5. Пройдена автоматическая проверка `ECHO 1.0 Quality Gates` и Android APK build.
6. Никакой неподтверждённый персональный AI-голос не помечен как готовый.
7. Перед публикацией в магазине: правила конфиденциальности, разрешения, скриншоты, страница поддержки и возрастные требования магазина проверены отдельно.
