# ECHO — сценарий демонстрационного видео (75–90 секунд)

**Цель:** продемонстрировать основные возможности на вымышленных данных. Это **сценарий**, не готовый видеоролик.

| Время | Экран/действие | Текст диктора (пример) |
|---|---|---|
| 0–8 c | Логотип ECHO и главный экран Executive Light | «ECHO — приложение альтернативной коммуникации. Оно помогает выражать повседневные просьбы через карточки и озвучивание». |
| 8–18 c | Выбрать стандартную карточку «Я хочу пить» | «Одно нажатие — и устройство произносит заранее подготовленную фразу». |
| 18–28 c | Создать новую демонстрационную карточку «Мне нужна тетрадь» | «Фразы можно добавлять и менять под свои потребности». |
| 28–38 c | Избранное и быстрые фразы | «Самые нужные сообщения легко найти». |
| 38–47 c | Конструктор предложений | «Из отдельных слов можно собрать новое сообщение». |
| 47–57 c | Показать настройки: простой режим, размер карточек, контраст | «Интерфейс адаптируется под предпочтения пользователя». |
| 57–68 c | На подготовленном тестовом профиле экспортировать резервный JSON-файл | «Данные можно сохранить в отдельную резервную копию. Не передавайте файлы с личным голосом другим людям». |
| 68–77 c | Режим полёта: нажать сохранённую карточку с локальной записью | «Базовое общение рассчитано на работу без интернета. Для некоторых системных голосов нужны установленные офлайн-пакеты». |
| 77–88 c | Экран цели проекта, QR-код только после реальной публикации | «ECHO развивается как бесплатный AAC-инструмент. Следующий шаг — испытания доступности и удобства на реальных устройствах». |

## Требования к съёмке

- Показывать только вымышленные карточки, тестовые изображения и записи, которые созданы специально для демонстрации.
- Не показывать имена пользователей, личные записи, системные уведомления с данными, ключи, пароли, токены или приватные файлы.
- Не нажимать кнопку реального телефонного вызова 112 во время демонстрации.
- Не включать в ролик утверждение «AI-голос идеально работает на телефоне» — эта функция пока не подтверждена и модель в APK не встроена.
- Если показывается офлайн-режим, действительно перевести устройство в автономный режим и продемонстрировать реальное воспроизведение.
- Добавить субтитры и избегать слишком быстрого монтажа; звуковые действия дублировать текстовыми пояснениями.
