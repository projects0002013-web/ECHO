# ECHO — PocketTTS: ход интеграции локального AI-голоса

## Задача

Пользователь предоставляет **собственную** добровольно записанную речь, вводит новый текст, ECHO генерирует новую WAV-фразу **не отправляя запись и текст в облако**. Эта возможность требует настоящей модели, установленной локально в Android; она не равна воспроизведению заранее записанных фраз.

## Выбранная техническая основа

- PocketTTS (через sherpa-onnx) — English zero-shot TTS с коротким аудиообразцом, без обязательной транскрипции образца.
- Официальная документация модели: https://k2-fsa.github.io/sherpa/onnx/tts/pocket.html
- Официальный Java-пример конфигурации: https://github.com/k2-fsa/sherpa-onnx/blob/master/java-api-examples/PocketTts.java
- Источник Android/JNI-движка: https://github.com/k2-fsa/sherpa-onnx
- Официальные файлы модели PocketTTS — отдельные ONNX и vocab/json. **Не коммитить веса в репозиторий без проверки лицензий и размера.**

## Реализовано в ECHO

1. `PocketReferenceAudio.java` — нативная Java-проверка RIFF/WAVE/PCM. Проверяет формат mono 16-bit, sample rate 8–96 kHz, длительность 5–30 секунд, содержимое не должно быть тишиной; декодирует `float[]` в диапазоне [-1, 1] для будущего TTS runtime.
2. `tests/java/PocketReferenceAudioTest.java` — тестирует допустимые и ошибочные WAV, обрезанные/поддельные заголовки, некорректные длины, тишину и дополнительный WAV-чанк.
3. Android `MainActivity` принимает `aiReferenceCheck` по внутреннему JavaScript-мосту и проверяет образец в worker thread. Возвращает только результат проверки, длительность и частоту — **не отправляет аудио** в интернет и не сохраняет его.
4. `mobile-voice.js` добавляет `echoNativeVoice.checkReferenceWav` только для Android.
5. `offline-voice.js` показывает выбор проверяемого WAV в Android-приложении; на сайте без Android-моста кнопка не появляется.
6. Качественные проверки Java и Android входят в GitHub Actions.

## Не реализовано и не выдаётся за готовое

- [ ] Включить официальную библиотеку sherpa-onnx JNI/Java в Android APK с закреплённой проверяемой версией.
- [ ] Подготовить способ безопасной локальной установки ONNX-весов и проверки SHA-256/лицензии.
- [ ] Подключить `OfflineTts` + `GenerationConfig.referenceAudio` и реальную генерацию WAV в отдельном потоке.
- [ ] Подключить отмену и тайм-ауты для ресурсоёмкого inference.
- [ ] Сохранить выходную WAV в зашифрованном/локальном пользовательском хранилище по выбору владельца (оценить требования к шифрованию и ключам).
- [ ] Проверить работающий русский, казахский, белорусский и английский AI-синтез отдельно: **эта модель сейчас поддерживает только английский**. Для других языков потребуются иные модели.
- [ ] Фактически измерить пиковую память, время генерации и качество речи на Android.
- [ ] Проверить согласие владельца голоса и отсутствие незаметной передачи образцов.

**Статус:** подготовка голосового образца работает как программный компонент; сам AI-инференс в APK пока **не работает**. У существующих пользователей всегда остаются обычный системный TTS и сохранённые записи.
