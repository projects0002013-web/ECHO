# ECHO — PocketTTS Android: реализация и проверки

## Что изменилось (9 ноября 2026)

**Реальный персональный синтез теперь подключён в коде Android ECHO Тест.** Отсутствие физической проверки не позволяет пока называть Android-версию окончательно готовой.

### Интеграция

- `mobile/android/prepare-pocket-runtime.py` скачивает официальный sherpa-onnx **v2.0.1** Java JAR и Android arm64 JNI из GitHub Releases, с проверкой опубликованных SHA-256.
- `mobile/android/prepare-pocket-model.py` скачивает **sherpa-onnx-pocket-tts-int8-2026-01-26** (~98 МБ сжатый, 198 310 484 байта распакованных ресурсов). SHA-256 архива закреплён: `2f3b88823cbbb9bf0b2477ec8ae7b3fec417b3a87b6bb5f256dba66f2ad967cb`. Файлы модели добавляются в APK **только на этапе сборки**, не загружаются на телефоне.
- `PocketModelInstaller.java` при первом запросе копирует модель из APK во внутренние файлы Android и проверяет каждый файл по SHA-256. Модель не сохраняется на общедоступной SD-карте.
- `PocketReferenceAudio.java` строго проверяет личный WAV: RIFF, моно PCM 16-bit, 8–96 кГц, 5–30 секунд, не тишина.
- `PocketTtsEngine.java` создаёт настоящий `OfflineTts` с Pocket-моделью, вызывает `generateWithConfigAndCallback` с `referenceAudio`, возвращает настоящий WAV. Генерация выполняется вне UI-потока.
- `MainActivity.java` предоставляет локальный JS bridge: `status`, `aiReferenceCheck`, `synthesize`, `cancel`. Язык `en`; согласие владельца обязательно. Речь/образец не отправляются на сервер.
- `features.js` и `mobile-voice.js` подключают нативный синтез к Voice Studio и локальному кэшу новых фраз; `offline-voice.js` показывает состояние модели, но не рекламирует готовность на обычном сайте без нативного движка.

### Доказательства

- ✅ [GitHub Actions, настоящий Linux ONNX inference](https://github.com/projects0002013-web/ECHO/actions/runs/42547174434): тест с искусственным звуковым образцом и новым английским текстом создал **1 071 404 байта WAV за 5,11 с**. Это запуск настоящей модели, а не mock; он не измеряет качество сходства с голосом человека и не доказывает Android-производительность.
- ✅ [Android APK с встроенной моделью](https://github.com/projects0002013-web/ECHO/actions/runs/42546676817) собралась. Дополнительные сборки/браузерные проверки следует оценивать по последнему SHA рабочей ветки.
- ✅ [Тесты WAV декодера](tests/java/PocketReferenceAudioTest.java) и [тест настоящего инференса](tests/java/PocketTtsInferenceSmoke.java) встроены в CI.

### Ограничения и обязательные проверки

- [ ] Физически установить **ECHO Тест**, не заменяя стабильный ECHO.
- [ ] Проверить первый запуск модели, доступное место ~250 МБ и реальный расход RAM.
- [ ] Записать **свой** образец и дать добровольное согласие.
- [ ] Проверить, что по новому английскому тексту получается новая речь, а Stop прерывает генерацию.
- [ ] Оценить сходство с предоставленным голосом и понятность речи.
- [ ] Проверить отключение сети, перезапуск приложения, кэш и сохранность резервных копий.
- [ ] Проверить TalkBack, микрофон, воспроизведение и работу с файлами.
- [ ] Подобрать и отдельно лицензировать модель персонального синтеза для русского, казахского и белорусского, если это требуется. PocketTTS здесь **только английский**.
- [ ] Проверить финальные лицензии, подпись стабильного APK и сценарий обновления существующего `org.echo.aac`.
